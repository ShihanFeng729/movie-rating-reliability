# Documentation

This directory will contain durable project documentation, including:

- research and metric definitions
- architecture and data-flow decisions
- data-source licenses and attribution
- methodology, assumptions, and limitations

Current V1 documentation includes the real snapshot, data-quality audit,
reliability and model results, and the conditional sentiment-module decision
gate in [`sentiment-go-no-go.md`](sentiment-go-no-go.md).

The completed version is closed by the criterion-by-criterion evidence record
in [`v1-acceptance.md`](v1-acceptance.md).

V1.1 starts with the reproducible, local-only review selection documented in
[`v1-1-strict-text-sample.md`](v1-1-strict-text-sample.md).
Its fixed, interpretable text-scoring rule is documented separately in
[`v1-1-sentiment-baseline.md`](v1-1-sentiment-baseline.md).
